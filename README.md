## CONTACT BOOK PYTHON

## Project overview
A simple contact book built with python that allow user to 
add, view ,search ,update and delete contacts

## Features
1. add contacts
2. show all contacts
3.search contacts
4. update contacts
5. delete contacts
## Technology used
- Python
## How to run
```Bash
python contact_book.py
```
